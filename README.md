This is the first of the uncompleted Capstone Projects I never finished from The App Brewery's Complete Full-Stack Web Development Course on Udemy, the Blog Posting Project. I've decided to name this project Wafffle because the terms "waffling" and "waffle on" are often used to describe someone talking at length about a subject, and the extra "f" is there to be quirky, as everyone loves purposeful mispellings.

This project was simple, all things considered. A lot of the components I used in this project are components that I've already done, so a lot of it was just copying what I've already done. Of course, I had some help with FelipeHSMartin posting his own website, which helped me work through the logic that I've already forgotten.

The hardest part was getting the Main Blog List and Side Blog List to look the way it did, especially since I didn't use any Bootstrap in this project. At first, I tried to use grid to get it to work, but that had issues of its own, primarily getting the lists to have the same height. I eventually ditched the grid idea altogether, and worked the issue out a different way, and it worked beautifully.

One thing I did do to differentiate Wafffle from Bloop_Bloop_Blog (FelipeHSMartin's project), was the integration of the Hijri date, which taught me a lot about the Date() method and how it works with the toLocaleString() method. Getting it swap as I did was an interesting challenge.

All in all, I'd say it worked beautifully, and I'm glad it worked out the way it did. And I hope you enjoy the results.
